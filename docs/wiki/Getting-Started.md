# Getting Started with Real-Time_Sentiment_Analysis_on_X

## 📋 Prerequisites
- **Python** 3.10+ / **Node.js** 18+
- **Git** & **GitHub CLI**

## ⚡ Quick Start
```bash
# Clone the project repository
git clone https://github.com/Bosaj/Real-Time_Sentiment_Analysis_on_X.git
cd Real-Time_Sentiment_Analysis_on_X

# Run the evaluation harness
python scripts/eval_harness.py

# Run the QA test suite
python -m pytest tests/test_monitoring_and_qa.py
```
