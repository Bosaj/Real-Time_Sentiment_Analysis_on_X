# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability
We take security seriously. If you discover a security vulnerability within this repository:

1. **Do NOT open a public GitHub issue.**
2. Please privately disclose it by emailing **oussousselhadji@gmail.com**.
3. Include detailed steps to reproduce, impact assessment, and proof-of-concept if available.

We acknowledge receipt within 48 hours and provide a timeline for remediation.
